EOMasters Toolbox

  Overview

The EOMasters Toolbox is a collection of various tools which help to ease the daily work and to save valuable time while working with SNAP. The toolbox comprises the following tools, features and options:

  • Quick Menu
    Provides quick access to the most often used menu actions.
  • Loop GPT
    With Loop GPT several commands can be executed in one go.
  • IO-Formats Listing
    With the formats command you can list all the readable and writable data formats.
  • Band Maths Extensions
    Adds new functionalities to Band Maths, like window calculations and checking if pixels are invalid.
  • Wavelength Editor
    Allows to edit the wavelength properties of multiple bands and apply the changes to compatible products.
  •  Asset Library
    Stores frequently used sites, geometries, masks, and other resources for quick access.
  •  SpeX - Spectral Index Database
    Provides hundreds of spectral indices and supports custom definitions.
  •  PyEditor
    Edits and executes Python scripts directly in SNAP.
  •  Coastal Map
    Provides land-water, coastline, tidal-flat, and land/water-vicinity indicators.
  • Sentinel-2 Geometry Up-scaling
    Scales view and sun geometry grids to band resolution while respecting detector footprints.
  • Sentinel-2 5 m Super-Resolution
    Increases the resolution of 10- and 20-metre bands to 5 metres and can use a GPU for acceleration.
  • Sentinel-2 Surface Reflectance Normalisation
    Produces Nadir BRDF Adjusted Reflectance using the c-factor method.
  • Estimate a 620 nm band for Sentinel-2 over water
    Estimates data at 620 nm from the 665 nm band.
  • ASTER L1T Reader
    Reads ASTER Level 1 Precision Terrain Corrected Registered At-Sensor Radiance products.
  • EMIT L1B/L2A Reader
    Imports EMIT radiance and reflectance products, including optional ancillary files.
  • Close Product Without a View
    Simply closes all products which are not used by a Scene View.
  • Copy CRS WKT to Clipboard
    This actions can copy the CRS of the currently chosen node to the clipboard.
  • Generate System Report
    Generates a system report usable for error reports to the developers.
  • EO Data Database
    The database provides information about sources of EO satellite data.
  • Coastal Map Data Portal
    Opens the supporting Coastal Map data and documentation.
  • Options
    Allows to change the settings of the tools and to export them into a separate file, which can later be imported.
  • Error Handler
    In the unfortunate event of an error, this tool helps to create an error report and to send it to the developers.
  • Credits
    Credits for resources and tools used to build the EOMasters Toolbox.
