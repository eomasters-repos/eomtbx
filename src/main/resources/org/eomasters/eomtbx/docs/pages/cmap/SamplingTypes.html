  Sampling Types

For generating the Coastal Map data you can select between two sampling types. The Nearest Neighbour and the Aggregate type. The Aggregate sampling type should be used if the target resolution is significantly lower as the map resolution (10m).

Nearest Neighbour Based on the geolocation of a pixel the closest pixel in the map is selected.
Aggregate The pixels covered by the source pixels on the map are aggregated. The occurrence of the individual flags is counted. The target flag is set based on the number:
  • LAND - >50% of all counted pixels
  • WATER - <=50% of all counted pixels
  • COASTLINE - >0 of all counted pixels
  • INTERTIDAL - >50% of all counted pixels
  • COASTAL_WATER_VICINITY - The vicinity (LOW|MID|HIGH) with the highest count is set over land pixels
  • COASTAL_LAND_VICINITY - The vicinity (LOW|MID|HIGH) with the highest count is set over water pixels
