  Coastal Map

Satellites monitor coastal areas, which are important ecosystems for plants and animals. This allows us to study and protect these natural wonders. The provided coastal area map facilitates the analysis of Earth observation data. It offers data that is essential for processing coastal area information. This lowers the workload and the computing time, and thus speeds up the delivery of the ecological coastal map to customers and decision makers.

The map provides 4 important indicators for coastal areas.

  • a land-water indicator
  • a coastline indicator
  • a tidal flat indicator
  • a vicinity indicator for land close to water and water close to land

Generated Data

After generating coastal map data the product will contain the following items.

Flag Band

A new band contains the flag data named 'eom_cm_flags'

Flag Coding

A new Flag Coding named 'EOM_CoastalFlags' is created and defines the following flags.
LAND, WATER, COASTLINE, INTERTIDAL,
COASTAL_WATER_VICINITY_LOW, COASTAL_WATER_VICINITY_MID, COASTAL_WATER_VICINITY_HIGH,
COASTAL_LAND_VICINITY_LOW, COASTAL_LAND_VICINITY_MID, COASTAL_LAND_VICINITY_HIGH

Masks

For each flag a mask is created for visualisation in the scene view of snap. The default appearance of the masks can be changed in the options.

Note:
It is recommended to utilize the ZNAP data format when saving the product to disk. Other data formats, like BEAM-DIMAP and NetCDF4 do not preserve the flagging correctly. This problem has no effect on the actual data in the band. You can therefore use different data formats if you are simply concerned with the flag data and don't care how SNAP interprets it.
