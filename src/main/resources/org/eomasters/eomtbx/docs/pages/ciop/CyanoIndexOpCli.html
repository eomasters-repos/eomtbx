Cyanobacteria Index Processor (CLI)

Overview

The Cyanobacteria Index processor can be used with the command line tool gpt. General information about GPF and GPT can be found on their help pages. Specific help for the Cyanobacteria Index processor can be obtained with: ${SNAP-INSTALL-DIR}/bin/gpt -h CyanoIndex
This will show the following help:

Usage:
  gpt CyanoIndex [options]

Description:
  Cyanobacteria index (CI) for detection of cyanobacteria blooms.


Source Options:
  -SsourceProduct=<file>    The source product
                            This is a mandatory source.

Parameter Options:
  -Pshapefile=<path>            An ESRI shapefile, providing the considered geographical region(s).
  -PvalidExpression=<string>    The valid expression to be used for the spectral index.
  -PwktRegion=<geometry>        The considered geographical region as a geometry in well-known text format (WKT).

Graph XML Format:
  <graph id="someGraphId">
    <version>1.0</version>
    <node id="someNodeId">
      <operator>CyanoIndex</operator>
      <sources>
        <sourceProduct>${sourceProduct}</sourceProduct>
      </sources>
      <parameters>
        <validExpression>string</validExpression>
        <shapefile>path</shapefile>
        <wktRegion>geometry</wktRegion>
      </parameters>
    </node>
  </graph>

Parameters

sourceProduct This defines the source product on which the processing is performed. See the input requirements on the product.
shapefile A shapefile can be selected to define the valid region for the processing.
validExpression This expression defines which pixels are valid for processing. It must follow the rules of Band Maths.
wktRegion A geometry using WGS84 coordinates can be specified following the WKT format.

Mask Combination

The invalid pixels of bands used in the CI calculation, defined by the bands no-data value and valid-pixel expression, are used as masks by default. These masks are combined with the masks (shapefile, validExpression, wktRegion) using the logical AND operator.

Resampling of source data

If the used bands have different sizes they are resampled to the resolution of the center band. This is done by using the SNAP Resample operation with the default parameters. If a different resampling is required the source product should be resampled first.
