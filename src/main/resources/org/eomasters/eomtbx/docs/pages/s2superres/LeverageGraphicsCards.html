Leverage Graphics Cards

The S2 Super-resolution uses ONNX, an open format to represent machine learning models. Thanks to that, the operator can leverage the GPU to super-resolve the spectral bands using the ONNX Runtime.
If you have an NVIDIA GPU, you can install the CUDA Toolkit. This toolkit enables the algorithm to access the graphics card.
To get this running, you need to install the following:

  • CUDA Version 12.x ( )
    An installation guide for your operating system is provided at the download page.
