  PyEditor Overview

PyEditor is an editor to edit and execute Python code. The intention is to lower the barrier to developing scientific code using SNAP. PyEditor is easy to setup and always at hand when you work with SNAP. Also, a specialized Python package, named SnapKit, is provided. It makes the access to SNAP functionalities easy.

Beta Release
I mark this as Beta release. The SnapKit API is not final and a also the Editor can further be improved. Even though it has been thoroughly tested it is still possible that bugs are present. Also, the API can be further enhanced and extended. Let me know if you find any bugs or if you have any suggestions. Please report them in the EOMasters issue tracker[1]. On Linux native packages like numpy, scipy or matplotlib can be used. On Windows currently not. The developers of GraalPy are working on this.

Setup

The PyEditor only needs a GraalPy[2] installation. GraalPy is a Python runtime (v3.11) embeddable into a Java environment. On first use you are asked for the installation directory, and the download and installation start automatically.

SnapKit API

To make use of the SNAP Java API the Python SnapKit provides a pythonic wrapper. The wrapper does not cover the full Java API yet. But building processing graphs, reading and writing products, setting computed data to rasters is already possible. The API documentation can be found here. Also, several examples show the usage of the API.
