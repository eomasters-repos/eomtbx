  SpeX

SpeX (Spectral IndeX) allows you to easily manage and compute spectral indices. By default, more than 270 spectral indices are available, and you can also add your own spectral indices to the database. The database can be maintained by the SpeX Database Manager and data can be processed by using the SpeX Processor. It allows to compute multiple spectral indices with general masks (expression/WKT/shapefile) at once. In addition, it is possible to specify masks for each selected spectral index. Both are accessible from the Optical menu in the main menu bar beneath the SpeX entry. The processing can also be performed using the processor from the command line. The command line interface is described in the SpeX Processor (CLI) section.

The predefined spectral indices are taken from the following sources:

  • Awesome Spectral Indices v0.7
  • Index Database (August 2024)

Some additional indices that are not included in one of the public databases have been added by EOMasters.

Spectral indices are mathematical formulas that use different spectral band values of an image to highlight some features or properties of the objects in the image. For example, spectral indices can be used to measure the amount of vegetation, water, soil, snow, or fire in a given area. If you want to learn more about spectral indices and their usage the following two articles from GEO University can be a good entry:

  • Spectral Indices with multispectral satellite data
  • Spectral Indices in Remote Sensing and how to interpret them
